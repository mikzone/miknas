## 工作空间介绍

### 工作空间组成

1. 工作区(Space)
   表示我们直接操作的相关目录
2. 插件(Plugin)
   简单来说就是在特定的目录执行相关操作的一系列功能
   它的组成：
   1. 作业(Job)
   2. 描点(Anchor)
      如果当前目录下有该描点文件，(比如svn相关，会在顶部目录有个.svn文件夹)

在实际运行中，执行一个Plugin的Job，通常会涉及这几个概念:

1. PluginWorkRoot
   比如svn插件，其实就是离当前文件夹最近的一个含有anchor(.svn)父文件夹
2. PluginWorkDir
   表示当前运行的目录，也就是cwd
